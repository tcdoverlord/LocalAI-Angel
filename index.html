Install, start, and stop Angel on Windows

Use the Angel Control Center for the easiest setup and everyday operation. Docker Desktop must be installed and running before you install, start, or manage the platform.

Before you begin: Open Docker Desktop and wait until its engine reports that it is running. Keep Docker running while installing and while using Angel. The first installation can take a while because services and the default model may need to download or build.

Download LocalAI-Angel

Download the ZIP from GitHub and extract the repository to your preferred folder. For example:

D:\LocalAI-Angel

Open the LocalAI-Angel repository ↗

Start Docker Desktop

Install Docker Desktop if you do not already have it. Launch Docker Desktop and wait until the Docker engine is fully running before opening the installer or Control Center.

Open the Control Center

Open the project's dist folder and double-click the Control Center executable:

dist\AngelControlCenter.exe

Keep the project folder structure intact so the Control Center can find the batch scripts.

Install or repair — first-time setup

In the Control Center, click INSTALL / REPAIR. This runs the installation workflow to prepare the LocalAI-Angel services and required components. Follow the on-screen progress and allow downloads and builds to finish. Do not close Docker Desktop during installation.

Start Angel for everyday use

Once installation has completed, open dist\AngelControlCenter.exe and click START ANGEL. The Control Center starts the configured Docker Compose services. Wait for startup to complete, then open the local interfaces below.

Stop Angel when finished

Open the Control Center and click STOP ANGEL. This stops the configured services. Persistent application data and model volumes are intended to remain in place, so you do not need to reinstall every time you want to use Angel again.

Everyday workflow: Start Docker Desktop → open dist\AngelControlCenter.exe → click START ANGEL. When finished, click STOP ANGEL. Use INSTALL / REPAIR for the initial setup or when you need to repair the installation.
First launch: allow internet access for the initial image, source, and model downloads. The default model is qwen2.5:3b and is not bundled in the ZIP. Download and build time depends on your internet connection and hardware. Never share API keys, tokens, or private .env files.

How model selection works

  • Angel uses LocalAI when LocalAI has a chat model available.
  • If LocalAI has no chat model, Angel can fall back to the provisioned qwen2.5:3b model.
  • The default Ollama model is stored separately from LocalAI's model gallery; it is not automatically copied into LocalAI.
  • Free-form AI reasoning requires a language model. Some deterministic date/time, weather, and knowledge routes can work without one, depending on configuration.

If a local URL does not open, confirm Docker Desktop is running, click START ANGEL in the Control Center, and wait for the services to finish initializing. Check the Control Center output or use the repository's diagnostic utility if needed.
