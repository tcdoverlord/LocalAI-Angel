# Computing and Digital Literacy

## Computational thinking
Computational thinking often involves decomposing a problem, identifying patterns, abstracting away irrelevant detail, writing an algorithm, and testing the result. An algorithm is a sequence of instructions for a task. Students should test normal cases, edge cases, and invalid inputs, and explain why their solution works.

## Programming foundations
Core ideas include variables and data types, expressions, decisions, loops, functions, collections, input/output, debugging, and decomposition into reusable components. Begin with a precise expected result; then create the smallest example that demonstrates it. When a program fails, inspect the error message, identify the relevant line, isolate a minimal test, and make one change at a time.

## Data and AI literacy
Data are collected for a purpose and may be incomplete, biased, outdated, or misinterpreted. A machine-learning model learns patterns from data rather than possessing guaranteed truth. Generative AI can produce plausible but incorrect statements, invented citations, or code with defects. Verify facts against suitable sources, run code in safe environments, protect private information, and disclose AI assistance when school policies require it.

## Cybersecurity and privacy
Use strong unique passwords, multifactor authentication where available, software updates, backups, and careful link checking. Never share passwords, recovery codes, private student data, personal addresses, or sensitive family information in an unsecured prompt. Report suspected phishing or unsafe contact to a trusted adult or the school's designated staff. Do not attempt unauthorized access, credential theft, malware, or bypassing controls.

## Digital citizenship
Communicate respectfully, consider the audience and permanence of online posts, respect copyright and licenses, attribute sources, and ask permission before sharing others' images or information. Rules for acceptable use vary by school and service; follow the applicable policy.

## Safe project workflow
1. Keep a copy of source files and use version control when available.
2. Read instructions before running code.
3. Avoid running unknown scripts with administrator privileges.
4. Test on sample data before real data.
5. Keep credentials out of source code and logs.
6. Confirm changes and preserve a rollback path.
