Angel AI: start talking, then explore

The goal is to make the first step into AI simpler: use the Angel starter experience without having to assemble every component yourself first.

Connected starter: Angel AI's ready-to-use path requires internet access and is intended to work at no cost through the configured provider's available free access. Provider limits, account requirements, and terms can change. This is not the same as fully offline inference.

For local inference, LocalAI can serve compatible models on your own system. The experience depends on your hardware, selected model, and configuration.

Install and launch Angel on Windows

Follow these steps for the unified build. The first startup builds the LocalAI fork and downloads the default model, so it may take a while and needs substantial free disk space.

Download the project

Open the GitHub repository, select Code → Download ZIP, and extract it to a folder such as D:\\LocalAI-Angel-Unified.

Open repository ↗

Start Docker Desktop

Install Docker Desktop if needed, open it, and wait until its Linux engine is running. Close the standalone Angel Harness app first if it uses the same Angel_Platform data directory.

Start the unified build

In the extracted project folder, double-click this launcher and keep its window open while services start:

START_ANGEL_UNIFIED.bat
First launch: the model-init service downloads qwen2.5:3b into a persistent Docker volume. The model is not bundled in the ZIP. Keep internet access available and allow time for the download and initial LocalAI source build. Never share API keys, tokens, or private .env files.

Open Angel, LocalAI, and Nexus

After the services finish starting, open the local interfaces below. These URLs work on the computer running the containers; they are not public internet addresses.

How model selection works

  • Angel uses LocalAI when LocalAI has a chat model available.
  • If LocalAI has no chat model, Angel can fall back to the provisioned qwen2.5:3b model.
  • The default Ollama model is stored separately from LocalAI's model gallery; it is not automatically copied into LocalAI.
  • Free-form AI reasoning requires a language model. Some deterministic date/time, weather, and knowledge routes can work without one, depending on configuration.

Stop the services

When finished, run STOP_ANGEL_UNIFIED.bat from the project folder. The model is stored in a persistent Docker volume, so stopping the services is not intended to delete it.

If a URL does not open, check that Docker Desktop is running and that startup has completed. Inspect the launcher output and use the repository's DIAGNOSE_ANGEL.bat utility if needed.
